 Travel Booking Management System

 Project Overview
The Travel Booking Management System is a Python-based mini-project that allows users to select travel destinations, enter the number of travelers, calculate trip costs, apply discounts and confirm bookings.

The project demonstrates basic Python programming concepts and Object-Oriented Programming (OOP).

 Features
- Displays available travel destinations with codes, categories and fares.
- Allows users to select destinations using unique codes.
- Accepts the number of travelers.
- Automatically calculates the total travel cost.
- Applies discounts based on the number of travelers.
- Updates the destination booking status.
- Stores and displays confirmed booking details.
- Validates destination codes and traveler count.

 How to Run the Project

1. Install Python 3 or open Jupyter Notebook.
2. Create a new Python notebook.
3. Copy the complete project code into a single cell.
4. Run the cell using Shift + Enter.
5. Select a destination by entering its code.
6. Enter the number of travelers.
7. View the calculated fare, discount and booking confirmation.

 Project Limitations
- Destination information is predefined.
- Booking details are stored temporarily in memory.
- No online payment facility is available.
- No permanent database storage is implemented.
